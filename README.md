# ETS2 & TruckersMP Live Traffic Overlay

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Un'applicazione Python leggerissima per monitorare il traffico in tempo reale nei server multiplayer di **TruckersMP** per **Euro Truck Simulator 2**.

## 🚀 Caratteristiche
- **Mappa Interattiva Live:** Integrazione con l'API pubblica di TruckersMP.
- **Indicatori di Traffico In Tempo Reale:** Codifica a colori (Verde/Arancione/Rosso) in base all'affollamento delle strade (es. tracciato Calais-Duisburg).
- **Integrazione Overlay:** Compatibile con OBS Studio, Streamlabs o browser trasparente in-game.

## 🛠️ Requisiti

- Python 3.8 o superiore
- Dipendenze elencate in `requirements.txt`
